브라우저 검증 스크립트는 `qa-scripts/`에 있습니다. QA URL은 테스트용 메모리 저장소를 사용하므로 실제 진행 기록에 영향을 주지 않습니다.

실행 예: `npx --yes --package @playwright/cli playwright-cli -s=ocean open "http://127.0.0.1:8765/?qa=1"` 후 항해를 시작하고 `run-code --filename output/playwright/qa-scripts/touch-expandedqa.cjs --raw`를 실행합니다.

단일 게임 파일은 저장소 루트 `index.html`입니다. 스크린샷 및 스크립트는 실행에 필요하지 않습니다.
